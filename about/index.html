About Sifsci

Sifsci is an independent software studio building tools for creative work.

What we’re building

We’re building Sifcut, a video editor for Android. It starts with a simple workflow: select footage on your phone, work with it in a project, preview the result and export a video.

Sifcut is still in development. We’re using this phase to improve how it feels to move through an edit on a phone, from importing the first clip to saving the final video.
